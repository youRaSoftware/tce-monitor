# tce-monitor

Бот-мониторинг билетов на спектакли на [tce.by](https://tce.by) (онлайн-касса белорусских театров).

Каждые 30 минут заходит на афиши театров, собирает все актуальные спектакли, проверяет наличие свободных мест и шлёт уведомление в Telegram-группу когда билеты появляются.

## Как это работает

- Крутится на GitHub Actions — бесплатно, без своего сервера.
- При каждом запуске собирает афиши указанных театров (одним заходом получает все даты автоматически).
- Для каждого спектакля проверяет схему зала и считает свободные места.
- Если для спектакля раньше билетов не было, а сейчас появились — шлёт пуш в Telegram-группу.
- Если за раз появилось много (>5 спектаклей) — шлёт сводное сообщение, чтобы не было спама.
- «Ленивое прорежение»: спектакли которые подряд показывают 0 мест проверяются реже (раз в час, потом раз в 3 часа). Это экономит время и снижает нагрузку на tce.by.

## Какие театры отслеживаются

- Белорусский государственный театр кукол


- Театр юного зрителя (ТЮЗ)

Чтобы добавить ещё — открой `tce_monitor.py` и допиши блок в `THEATERS` со своим `base` ID (его можно взять из URL афиши на tce.by, параметр `?base=...`).

## Как редактировать что мониторим

В `tce_monitor.py` сверху есть конфиг `THEATERS`. У каждого театра поле `watch_titles`:

- `[]` (пусто) — следить за **всеми** спектаклями этого театра
- `["Идиоты", "Любовь и голуби"]` — только за спектаклями где в названии встречается одно из этих слов

После любого изменения в файле — закоммитить и запушить, GitHub Actions подхватит автоматически.

## Запуск вручную (если нужно сразу проверить)

Зайти в репозиторий → вкладка **Actions** → слева **TCE Monitor** → справа **Run workflow** → зелёная кнопка в выпавшем окошке.

## Запуск локально (для разработки)

```bash
pip install -r requirements.txt
playwright install chromium
export TELEGRAM_BOT_TOKEN="..."
export TELEGRAM_CHAT_ID="..."
python3 tce_monitor.py
```

Для отладки можно сделать разведку любой страницы — сохранит HTML и скриншот в `debug/`:

```bash
MODE=discovery DISCOVERY_URL="https://tce.by/index.html?base=..." python3 tce_monitor.py
```

## Технические детали

- Сайт защищён [Anubis](https://github.com/TecharoHQ/anubis) — Proof-of-Work анти-бот. Обходится автоматически через Playwright (настоящий Chromium решает PoW в браузерном движке).
- На страницах афиш и спектаклей часть данных грузится через AJAX. Скрипт явно дожидается появления нужных элементов в DOM.
- Состояние (что сколько мест показывало в прошлый раз) хранится в `tce_state.json` и автоматически коммитится в репо после каждого прогона.
- На GitHub Actions scheduled workflows автоматически отключаются при отсутствии активности в репо 60 дней. Достаточно периодически коммитить что угодно для сброса этого таймера.

## Замечания

- На страницах афиши tce.by билетов часто нет — многие театры продают через свои сайты, а сюда приходят только возвраты или допродажи. Это нормально, для того и нужен мониторинг.
- Уведомления приходят с задержкой 30-50 минут от появления билетов (cron + время на полный обход). Для редких возвратов этого хватает, для массовых волн — нет.
